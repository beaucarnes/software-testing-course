# TC-A11Y-001: Verify All Images Have Descriptive Alt Attributes

## Requirement ID
NFR-A11Y-001

## Module / Test type / Technique
Accessibility / Usability & GUI / Checklist

## Preconditions
- The TechMart application server is running at `http://localhost:3000`.

## Test data
| Target Pages | `/`, `/cart.html`, `/checkout.html`, `/login.html`, `/register.html` |
| Image Tag Selector | `img` |

## Test steps
1. Navigate to the homepage (`http://localhost:3000/`).
2. Query all `<img>` elements in the DOM.
3. For each image, inspect its `alt` attribute value.
4. Verify that `alt` is non-empty and provides meaningful context (e.g., product name or icon description).
5. Verify that images include fallback handling (e.g. `onerror="this.src='images/placeholder.svg'"`).
6. Repeat checks on `/cart.html`.

## Expected result
- Every image on the tested pages possesses a valid, descriptive `alt` attribute.
- No image has a missing or undefined `alt` attribute.
- Screen readers can interpret the meaning of visual assets.
