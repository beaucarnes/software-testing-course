# TC-A11Y-002: Verify Accessible Form Controls and Input Labels

## Requirement ID
NFR-A11Y-002

## Module / Test type / Technique
Accessibility / Usability & GUI / Checklist

## Preconditions
- The TechMart application server is running at `http://localhost:3000`.

## Test data
| Target Pages | `/login.html`, `/register.html`, `/checkout.html` |
| Interactive Form Inputs | `input:not([type="hidden"])`, `select` |

## Test steps
1. Navigate to `/login.html`.
2. Locate all visible input fields.
3. For each input with an `id`, check for an associated `<label for="[id]">`.
4. If no explicit label tag is found, verify presence of `aria-label` or `placeholder`.
5. Repeat the verification on `/register.html` and `/checkout.html`.

## Expected result
- Every interactive form field is properly labelled via `<label>`, `aria-label`, or explicit descriptive placeholder.
- Form inputs are accessible to assistive screen readers and keyboard tab navigation.
