# TC-A11Y-003: Automated WCAG 2.0 AA Accessibility Compliance Check

## Requirement ID
NFR-A11Y-004

## Module / Test type / Technique
Accessibility / Compliance & Quality / Benchmark (Axe Core)

## Preconditions
- The TechMart application server is running at `http://localhost:3000`.
- Automated test engine equipped with `@axe-core/playwright`.

## Test data
| Standard / Tags | `['wcag2a', 'wcag2aa']` |
| Impact Threshold | 0 critical violations |

## Test steps
1. Open page `http://localhost:3000/`.
2. Inject Axe Core accessibility scanner into the active page context.
3. Run accessibility evaluation targeting WCAG 2.0 Level A and Level AA rule sets.
4. Filter scan findings for violations with impact rating `'critical'`.
5. Assert violation list count.

## Expected result
- Axe Core scan completes without engine crashes.
- Number of critical accessibility violations is exactly 0 (`violations.filter(v => v.impact === 'critical').length === 0`).

Not Run / None
